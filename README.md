# Русификатор Desolate Planet — A Crash Landing Remake

Русификатор для Minecraft-сборки **Desolate Planet — A Crash Landing Remake**.

### О переводе

Перевод создан с помощью **Gemini 4 Argon**.

- переведены основные надписи;
- переведены задания и описания квестов.

### Установка

1. Файлы из папки `quests` необходимо закинуть в папку сборки с заменой существующих файлов.
2. Ресурспак необходимо активировать в настройках Minecraft.

### Примечание

Перевод может содержать ошибки и неточности. Прошу прощения, если вы столкнётесь с ними.

Приятной игры!
